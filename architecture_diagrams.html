sequenceDiagram autonumber actor Requester as Requester (Student A) participant NextApp as Next.js App / API Layer participant KarmaSvc as Karma Engine (lib/karma.js) participant DB as PostgreSQL / DB Pool actor Helper as Helper / Lender (Student B) Note over Requester, Helper: 1. Request Creation Requester->>NextApp: POST /api/requests (Academic / Project / Item) NextApp->>KarmaSvc: Check Requester Balance >= 10 pts KarmaSvc-->>NextApp: Balance verified (Eligible) NextApp->>DB: INSERT into requests (status: 'open') Note over Requester, Helper: 2. Peer Matching & Privacy Unmasking Helper->>NextApp: POST /api/offers (with help message) Requester->>NextApp: PATCH /api/offers/accept (Accept Offer) NextApp->>DB: UPDATE requests status -> 'in_progress' NextApp->>DB: INSERT into exchanges (status: 'active') NextApp-->>Requester: Contact Info Unmasked (Student B) NextApp-->>Helper: Contact Info Unmasked (Student A) Note over Requester, Helper: 3. Exchange Completion & Atomic Settlement Requester->>NextApp: POST /api/exchanges/[id]/complete NextApp->>KarmaSvc: Execute transferKarma(exchange_id) rect rgb(235, 248, 255) Note over KarmaSvc, DB: Atomic DB Transaction KarmaSvc->>DB: Requester (A): -10 pts (Debit) KarmaSvc->>DB: Helper (B): +20 pts (Credit) KarmaSvc->>DB: INSERT 2x rows into karma_txns KarmaSvc->>DB: UPDATE exchanges status -> 'completed' end Note over Requester, Helper: 4. Peer Trust Feedback Requester->>NextApp: POST /api/ratings (1 to 5 Stars + Feedback) NextApp->>DB: INSERT into ratings & Recalculate Trust Score
